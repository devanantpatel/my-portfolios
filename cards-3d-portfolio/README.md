# 🃏 3D Cyber Deck Portfolio

A futuristic, high-tech web portfolio featuring interactive 3D perspective cards, dynamic gyroscopic tilt mechanics, light sheen glare effects, and a cyberpunk HUD aesthetic.

* **🌐 Live Deployment:** [anant-3d-portfolio.netlify.app](https://anant-3d-portfolio.netlify.app)
* **📁 Parent Hub:** [my-portfolios](../README.md)

---

## ✨ Features & Architecture

* **Gyroscopic 3D Tilt Engine:** Real-time mouse and touch-drag mathematical coordinate translation (`rotateX`, `rotateY`) simulating true 3D spatial depth.
* **Dynamic Glare / Sheen:** Responsive radial lighting overlay shifting dynamically relative to the pointer angle.
* **Deck Carousel Navigation:** Smooth carousel state engine supporting step buttons and pagination indicators.
* **Cyberpunk HUD UI:** Monospace coordinate tags, pulsing status nodes, and neon cyan accents.

---

## 🛠️ Tech Stack
* HTML5 (Preserve-3D Perspective Canvas)
* Modern CSS3 (Custom Variables, 3D Transforms, Backdrop Blur)
* Pure Vanilla JavaScript (Mathematical Vector Tilt Engine)
* Netlify Edge Deployment
