## 🚀 1. Autonomous Spider Crawler Portfolio

* **🌐 Live Link:** [Click Here to View Live](https://devanantpatel-spider.netlify.app) *(Deploy ke baad Netlify link yahan update ho jayegi)*
* **📁 Source Code:** [`/spider-crawler-portfolio`](./spider-crawler-portfolio/)
* **🛠️ Tech Stack:** Pure JavaScript, HTML5 Canvas (Inverse Kinematics), CSS3, Web3Forms API, GitHub REST API.

### ✨ Key Features
- **Persistent Viewport Spider:** Procedural 8-legged arachnid simulation using Inverse Kinematics (IK) bones that reacts dynamically to mouse movement and viewport scrolls.
- **Autonomous DOM Indexing:** Simulates real-time search engine crawler behaviors by detecting visible DOM nodes and applying vibrant neon multi-color highlights.
- **Dynamic Palette Shuffling:** Randomizes cyber theme colors across the entire DOM and spider skeleton on every reload.
- **Live GitHub Project Sync:** Automatically fetches public repositories from GitHub with built-in client-side pagination.
- **Working Transmission Form:** Direct terminal message delivery straight to inbox via Web3Forms integration.
