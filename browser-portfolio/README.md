# 🌐 AnantWeb — Google Browser Simulator Portfolio

A simulated browser ecosystem mimicking the desktop/mobile Chrome experience with multi-tab navigation, intent-ranked organic search queries, auto-suggestions, and an active Web3Forms communication pipeline.

* **🌐 Live Deployment:** [anant-browser-portfolio.netlify.app](https://anant-browser-portfolio.netlify.app)
* **📁 Parent Hub:** [my-portfolios](../README.md)

---

## ✨ Features & Architecture

* **Simulated Chrome Window:** Custom multi-tab engine (`Home`, `About`, `Projects`, `Skills`, `Contact`) with interactive address bar synchronisation.
* **Smart Intent Search:** Dynamic search bar featuring keyword auto-suggestions and intent reordering for direct query routing.
* **Organic Search Engine Interface:** Pixel-accurate Google mobile search UI clone with profile avatar, query filter pills, and link cards.
* **Connected Message Transmission:** Direct email forwarding via Web3Forms integration to `devanantpatel@gmail.com`.

---

## 🛠️ Tech Stack
* HTML5 (Semantic Browser Shell)
* CSS3 (Variables, Flexbox, Fluid Media Queries)
* Vanilla JavaScript (Query Matcher, History Stack, Fetch API)
* Web3Forms API Pipeline
* Netlify Edge Deployment
