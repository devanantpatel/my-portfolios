# 🕷️ Autonomous Spider Crawler Portfolio

An interactive, dark-cyber themed developer portfolio featuring procedural limb inverse kinematics, autonomous DOM element patrol, dynamic GitHub repositories sync, and active contact pipeline.

* **🌐 Live Deployment:** [anant-spider-portfolio.netlify.app](https://anant-spider-portfolio.netlify.app)
* **📁 Parent Hub:** [my-portfolios](../README.md)

---

## ✨ Features & Architecture

* **Procedural Inverse Kinematics (IK):** Custom multi-segment leg physics rendering smoothly via HTML5 Canvas API, reactive to cursor tracking and scroll velocity.
* **Autonomous Target Patrol:** Scans DOM headings and skill badges, coordinates spatial targets, and systematically anchors across elements.
* **Dynamic Color Seeds:** Shifts procedural accent color palettes dynamically across active user sessions.
* **Live GitHub Integration:** Asynchronous client-side fetching with pagination controls.
* **Secure Contact Channel:** Client-to-email form submission pipeline powered by Web3Forms.
