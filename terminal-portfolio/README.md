# 💻 Interactive Developer Terminal Portfolio

A responsive, lightweight CLI-themed web portfolio simulating a Unix/Zsh terminal environment with procedural Matrix rain, dynamic theme switching, command history navigation, and integrated contact channels.

* **🌐 Live Deployment:** [anant-terminal-portfolio.netlify.app](https://anant-terminal-portfolio.netlify.app)
* **📁 Parent Hub:** [my-portfolios](../README.md)

---

## ✨ Features & Architecture

* **Interactive Command Parser:** Supports system commands (`help`, `about`, `skills`, `projects`, `contact`, `theme`, `clear`, `history`).
* **In-Window Matrix Rain:** Procedural canvas-based digital code fall animating directly inside the terminal viewport.
* **Dynamic Palette Cycling:** Real-time CSS custom property switching across Default Dark, Matrix Green, Cyberpunk Neon, and Classic Amber themes.
* **Shell Navigation Ergonomics:** Keydown event handling for `Up`/`Down` arrow command history and `Tab` auto-completion.
* **Mobile-First UX:** Quick-action command chips enabling one-tap command dispatch on mobile viewports.
